## 정적 장애물 M2 / 음영 M8

`new_lane/scripts/obstacle_info_merger.py`에서 확인된 정적 점유에 부모 ID를 부여한다. 원거리 제안과 근거리 검출이 인계될 때 외곽 크기를 보존한다. 검출이 사라져도 자차 후단이 장애물 외곽을 완전히 지나기 전까지 충돌 검사 대상으로 유지한다. 원본 관측 시각과 실제 측정 위치는 따로 유지하며, 확인된 움직임은 정적 보존보다 우선한다. 미확정 단발 점은 보존하지 않는다. 다른 미션으로 전환하면 캐시를 초기화한다.

경로 생성 후와 이전 경로 재사용 시 모두 최신 장애물 점유, 연석 경계, 곡률을 검사한다. 통과 전 안쪽으로 갑자기 줄어드는 경로는 이전 경로가 여전히 안전할 때만 억제한다. 연속 장애물의 기존 단계별 경로 생성은 유지한다.

M2 이전에는 인지와 별도 `/obstacle_avoidance/preview_path`만 준비한다. 이 준비 경로는 MPC 제어 경로로 전달하지 않는다. 기본 준비 범위는 lane 0의 idx 2200–2600이며, 활성 M2가 우선한다.

음영구간의 배경 이동 후보도 일반 장애물처럼 실제 회피 경로의 유효 길이와 차량 이동 시간에 따라 충돌을 검사한다. 경로가 오래되거나 짧으면 기준경로 기반 보수적 판정으로 돌아간다. 정적 부모의 관측 이력과 정적 증거를 활용하되 실제 측정 이동이 확인되면 정지를 유지한다. 기존 정지 유지 시간 1.2초는 그대로다. 정지 진단에는 검사 경로, 판단 이유, 유지 시간 정보를 추가했다.

## 고주로

- SMPC가 선택한 합류 공간의 앞차/뒤차 ID를 ACC에 전달한다. 앞지른 차량을 새 앞차로 잘못 추종하지 않는다. 앞 경계가 없는 공간에는 선택 앞차 ACC를 적용하지 않는다. 선택 앞차가 누락되면 가속을 억제하고 기존 앞차 안전 제한을 사용한다.
- 선택 앞차의 범퍼 간 추종 목표는 **8.5m**. 우리 차선 ACC와 물리적으로 겹치는 차량의 감속 권한은 유지한다.
- 우리 차선 앞차/유실 앞차의 실제 ACC 속도 제한을 공간 도달 예측에 반영한다. 양보 출력 자체가 다시 독립 제한으로 되먹임되지 않도록 별도 상태 필드를 사용한다. 독립 제한이 낮으면 예측 최저 속도보다도 우선한다.
- 별도 12m 앞 간격에 의한 차로 끝 감속 조건을 제거했다. 최신 SMPC가 아직 합류를 승인하지 않은 경우의 차로 끝 정지 보호는 유지한다.
- 속도 신뢰값을 차량 ID별로 보존하고, 모호하지 않은 가까운 ID 인계에만 이전 값을 전달한다.
- 미확정 소형 물체를 `current_front`로 사용하는 폭: `target_selector.yaml`의 `unknown_current_corridor_half_width_m: 1.10` (차량 반폭 0.95m + 0.15m). 확인된 차량에는 기존 차로 판정을 유지한다.
- 기존 ACC 마커에는 실제 속도 제한 차량을 표시하고, 같은 토픽에 `GAP LEADER` / `GAP FOLLOWER` 표기를 추가했다.
