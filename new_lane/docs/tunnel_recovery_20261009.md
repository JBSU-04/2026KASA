`config/tunnel_static_3d.npz`: 실제 측정한 344스캔, 배경 1,751,921점, 노면 399,135점. 5cm 복셀 안 측정점 평균이며 UTM 원점은 double, 저장 좌표는 원점 기준 float32이다. 측정한 접근/출구도 포함한다. 장애물 주행을 지도에 자동 추가하지 않는다. 미측정 셀은 미관측이다.

15cm 격자에서 3회 반복된 셀만 남기는 초기 제작 방식은 벽/턱의 실제 표면을 누락해 빈 터널에서도 선서행했다. 확인된 빈 주행의 실제 관측 표면을 5cm로 저장하는 방식으로 수정했다. 런타임 장애물 확정의 3점·2개 독립 스캔 조건은 별도이며 그대로 유지한다.

## 인지와 선서행

`/perception/points_gravity` → `tunnel_map_filter` → 기존 벽/인지 노드 및 전진 엔진.

Autoware 거리 기반 맵 비교의 3D 최근접 거리 커널을 scipy KD tree로 ROS1 이식했다. 전체 Autoware ROS2 노드를 실행하는 것은 아니다. 원본 4파일/버전/라이선스/해시는 `vendor/autoware_compare_map/UPSTREAM.json`에 보존했다.

점 필드:

| 값 | 뜻 |
|---|---|
| `map_label=0` | 미확인/관측 부족 |
| `1` | 3D 배경 일치 |
| `2` | 아직 2스캔 미충족 잔차 후보 |
| `3` | 3점 이상·2개 독립 스캔 확인 + 노면 확인 |
| `4` | 동일 확인 조건 충족, 노면 미확인; 보수적인 높이 제안 |
| `map_ground` | 확인한 센서 좌표 노면 높이; 없으면 NaN |
| `ground_relative` | 노면 위 높이 또는 미확인 상태의 보수적 높이 제안 |

국소 노면은 분산된 12개 이상 셀, 노면 잔차/기울기/XY 범위 조건을 통과해야 한다. 맵과 일치하지 않는 넓은 실제 노면의 작은 수직 정합 오차는 국소 높이가 거의 0인 경우에만 복구한다. 양의 물체 높이를 바닥으로 옮기지 않으며 이미 검증된 배경을 국소 모델로 취소하지 않는다.

확정 원시 잔차는 기존 장애물 추적기로 전달한다. GroundGrid의 제거 결과나 종전 센서 Z ROI 때문에 8cm 이상 후보가 사라지는 것을 방지한다. 추적 엔진 자체는 교체하지 않는다. 노면 미확인 후보는 정상 노면 확인 물체와 진단에서 구별한다.

벽 띠/길쭉한 형상만으로 잔차를 삭제하지 않는다. 실제 배경 일치가 필요하다. `/tunnel/wall_limits` 계산에는 `/tunnel/map_background`만 사용한다. 배경 스트림이 만료되면 실시간 벽 제한을 무효화하고 기존 실측 프로파일을 유지한다.

서 있는 맵 잔차도 선서행 후보이다. 링 사이에서 보이지 않는 구간을 위해 확정 원시 후보를 4초 기억한다. 동적 확정을 기다리지 않으며 회피 경로가 떨어져 있다는 이유로 면제하지 않는다. 초기 거리 20m, 기존 제한 6m/s를 유지한다. 실제 점이 없는 거리나 아직 관측하지 않은 구역의 검출을 보장하지 않는다.

## 정지와 전진 경로

M8 정지는 과거 경로나 옆 코리도 접촉만으로 유지하지 않는다. 현재 차체 위험과 앞으로 주행할 경로의 차체 이동 영역을 검사한다. 전진 엔진의 실제 점유 셀을 같은 검사에 사용하고, 만료 시 기존 물체 외곽 검사를 보수적으로 사용한다. 횡단/동적 위험은 유지한다.

전진 QP는 그대로 기본이다. M8에서는 장애물 사이에서 불필요한 중앙 종단 조건을 강제하지 않고, 차량 한계 내 저속 후보까지 검사한다. 실패 시 제한된 전진 Hybrid 탐색을 시도하고 검증된 경로를 끝의 안전 구간까지 보존한다. 경로 추종 오차·새 충돌·센서 만료는 정지 사유이다.

## 전진/후진 통합 탈출

Apollo 원본 Reeds–Shepp 소스를 수정 없이 컴파일한다. Hybrid A*의 차량 운동 확장을 ROS1 검색 어댑터로 이식했다. 전체 Apollo open-space 런타임을 이식한 것은 아니다. 원본 Hybrid/grid/node 소스도 SHA와 함께 보존했다. `occupancy_avoidance/THIRD_PARTY.md` 참조.

현재 자세에서 전진부터 찾고, 불가하면 R→D 한 번의 전환으로 장애물 이후 안전한 전진 상태까지 같이 찾는다. 끝점 QP 성공을 추가 승인 조건으로 요구하지 않는다. 전진 2m/s·후진 1m/s 상한, 후진 최대10m, 전체 경로 0.1m 이하 간격 차체 검사. 벽은 넘어갈 수 없는 경계, 장애물 여유0.2m, 벽 여유 차량 반폭+0.1m이다. 기억한 근거리/미확정/동적 예측 점유도 검사한다. 미관측 후방을 빈 공간으로 처리하지 않는다.

전진 검색 0.12s, 필요시 통합 검색 0.35s로 요청 검색 시간을 약0.5s 이내로 제한한다. 검색은 별도 스레드/지도 스냅샷을 사용한다. 새 지도에서 경로를 재검사하고, 정지 후 기어를 전환한다. 통합 경로에만 기존 절대15도 제한을 대체하고 경로 대비 횡0.3m·헤딩10도 기준을 적용한다. 탈출 전진 경로는 장애물 이후 안전한 꼬리 구간에서만 기존 QP로 인계한다.

차체 시작 위치가 점유와 겹치거나 후방 관측이 부족하면 승인하지 않는다. `start_body_collision`, `search_timeout`, 경로 없음은 구분한다. 모든 S자 배치의 통과를 보장하지 않는다.

## 헤딩 정합

X-ICP 원본 정합을 유지하고 입력을 최대800점으로 제한한다. 참고 지도/검색을 재사용하며 최신 스캔만 처리한다. `OMP_NUM_THREADS=1`, `OPENBLAS_NUM_THREADS=1`로 불필요한 병렬 실행을 제한한다. 반복 횟수·정합 품질 기준을 완화하지 않았다.

`/tunnel/xicp/yaw_measurement`는 유효 시각·양쪽 벽·yaw 관측 가능성·정합 품질을 모두 통과해야 발행한다. 기존 측위 어댑터가 관측 시각의 IMU와 비교해 heading bias를 보정한다. 실제 회피 회전각은 유지하며 터널 방향으로 강제로 맞추지 않는다. 주 측위 XY/SLAM 엔진은 교체하지 않았다. 맵 잔차 조회의 측방 보정도 실제 벽 일치도가 개선되는 경우에만 적용한다.
