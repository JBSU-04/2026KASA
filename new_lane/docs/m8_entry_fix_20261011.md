## 적용

- GroundGrid 원본의 지면 분류 알고리즘은 유지한다. GroundSegmentation의 원본 점 인덱스로 분류 라벨만 원본 센서 점에 연결하는 선택 출력을 추가했다. `/groundgrid/nonground_exact`는 큰 UTM 좌표를 float로 저장한 뒤 역변환하여 생기는 약 0.25m 정밀도 손실을 피한다. 기존 `/nonground` 등 다른 미션 입력은 그대로다. 기존 원본 저작권·라이선스를 유지한다.
- M8 C++ 맵 필터만 위 정밀 출력에 연결한다. 지도, 지면·높이 문턱, 배경 일치 거리, 센서 만료 시간은 변경하지 않았다. M8 원시 광선도 세계좌표를 float64로 만든다.
- M8 군집의 추가 중심거리 병합을 하지 않는다. 기존 0.38m 점 연결 결과와 실제 지지점을 유지한다. 큰 물체를 크기만으로 삭제하거나 장애물 사이의 빈 공간을 상자로 채우지 않는다.
- M8 운동 상태는 서로 다른 관측 3회와 0.2초 이상 표면 이력으로 검증한다. 원래 관측 표면이 겹치고 양쪽 면이 이동하지 않으면 정적으로 승인한다. dynamic은 양쪽 면의 일관된 이동과 유효한 기존 속도 측정, 연속 이동 증거를 함께 요구한다. 가림·입력 단절·정보 부족을 정적 증거로 사용하지 않는다. 기존 동적 물체의 5초 정지 후 전환은 유지하고 머저의 짧은 정지 조건이 이를 우회하지 못하게 했다.
- 확인된 unknown 물체의 실제 관측 셀을 계획에도 일시 점유로 전달한다. 정적 확정이나 회피 시작 승인으로 강제 승격하지 않는다. 최종 검사에만 나타나는 점유로 경로가 반복 거부되는 불일치를 줄인다.
- 정지 유지 해제는 원래 정지 원인 물체 ID 또는 관측 트랙 ID가 모두 연결되고, 신선한 정적 확정과 현재/향후 차체 영역의 안전이 확인될 때만 수행한다. 동적·미확정·미관측·근접 위험은 해제하지 않는다. 회피 실패 및 다른 정지 사유는 별도로 유지한다.
- M8 실시간 벽 경계는 실측 벽 프로파일을 넓히지 못한다. 중심 제한은 반폭 0.95m+여유 0.1m이며, 회전한 차체 모서리 검사도 유지한다. 생성, 연결, 탈출 경로의 검증이 같은 경계를 사용한다. 측정 벽이 없는 열린 입구에는 프로파일 벽을 새로 만들지 않는다.
