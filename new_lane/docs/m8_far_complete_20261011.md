# M8 원거리·접근 인지 연결 보완 — 2026-10-11

## 적용 구조

Raw 중력 정렬 + GroundGrid 원본 XYZ 비지면 → C++ 검증된 배경 제거와 같은 스캔 잔차 결합 → 공통 검출·추적 → 물체별 실제/보존 점유 → 정적 회피 및 동적 충돌 판단 → 최종 승인 경로.

- 기존 `/tunnel/nonground_filtered` 인터페이스와 원본 header 시각을 유지한다. 정상 결합 입력은 xyz/map_ground/map_label/ground_relative float32 필드다. 좌표가 정확히 같은 점만 중복 제거한다. 동일 점의 노면 높이가 다르면 검증된 맵의 국소 노면 높이를 사용한다. 검증된 배경과 불확실한 노면 잔차는 추가 장애물로 강제 확정하지 않는다.
- M2 원거리 제안과 M8 원거리 입력은 동일한 희소 연결 성분 알고리즘을 사용한다. M8은 0.55초·0.65m·누적 5점·2스캔 이력을 연결 증거로 사용하되 실제 현재 3점 이상만 검출에 전달한다. 과거 지지점을 현재 관측처럼 재발행하지 않는다. M2의 기존 후보 조건은 유지한다.
- M8 국소 노면 높이 0.08m·실제 3점, 서로 다른 스캔 확인을 유지한다. 단일 링의 저상 점을 고정 센서 z 하한 때문에 삭제하지 않는다.
- 실측 표면 겹침으로 ID를 연결하고, 부분 관측에 기존 정적 인증을 보존한다. 독립된 이동 증거는 인증을 해제한다. 좌표 기준 갱신은 표면 운동 이력도 함께 변환한다.
- 과거 동적 물체는 기존 5초 정지 후 경로 차단 전환을 거쳐야 한다. 미확정이나 관측 단절을 정지 증거로 강제하지 않는다.
- 승인 경로 전에는 신선한 기준경로의 차체 이동 영역 침범도 거리 기반 선감속 입력으로 전달한다. 승인 후에는 해당 정적 물체의 안전한 경로에 대한 물체별 해제 정책을 유지한다.
- 최종 발행이 거부한 현재/유지 계획 ID는 해제하고 재계획한다. 다른 계획 및 좌표 버전의 거부는 혼용하지 않는다.

## 접근과 유지 조건

- 기본 경로 `waypoint_system/data/default/3.csv`의 실제 선분 길이로 M8 시작점 앞 60m 인지 준비·40m 장애물 제어 경계를 계산한다.
- 현재 경로: csv3, 인지 준비 idx 6402, 제어 idx 6602, 종료 idx 8850. GPS 음영 시작 idx 7001, M7B/M8 ID 및 고주로 종료는 변경하지 않았다.
- 라우터는 신선한 인덱스와 공유 경계로 `/tunnel/random_obstacle_active`(Bool)를 발행하고 M7B 접근 제어 범위에서 static_obstacle/dynamic_obstacle 실행 권한을 추가한다. 머저와 엔진이 접근 활성 상태를 확인한다.
- M7B에서 회피 시 기존 M8 회피용 MPC 설정을 선택하도록 코드에서 별도 선택 키만 연결했다. 일반 M7B 속도와 모든 MPC 피팅 파일 수치는 변경하지 않았다.
- DR+X-ICP 기본 모드·300ms 정합 만료·관측당 0.2도 보정 제한, 기존 GPS/벽 지도, 코리도 1.3m, 장애물 0.2m 및 물리 경계 0.95+0.1m 여유를 유지한다. UFLD는 xicp 기본 모드에서 실행되지 않는다.
- 기존 5초 전환·통합 탈출·미관측 후방 거부·기어 전환·전진 인계를 유지한다. 입력 만료·동적 대기·계산 시간 초과는 후진 시작 사유가 아니다.

## 검사 결과와 한계

- 합성 검사 p95: 맵 23.7ms, 머저 20.5ms, 장면 1.2ms, 원본 스캔→계획 입력 154.7ms. 실제 토탈 런치의 성능 수치나 회피 성공으로 해석하지 않는다.

- 추가 백 재생은 하지 않았으며 실행 중인 주행 런치는 재시작하지 않았다. 차가 정지한 상태에서 전체 런치를 다시 시작해야 C++와 초기화 설정 변경이 적용된다.
- 사용자 검증 순서: 빈 터널 → 입구 큰 장애물 → 저상 정적 → 동적 횡단 → 5초 정지 후 회피 → 전진 공간 부족 시 후진 탈출. 실제 지연 p95≤250ms와 물리 여유·경로 추종은 이 주행에서 확인한다.
