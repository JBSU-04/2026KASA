# 정적·음영구간 회피 보완 (2026-10-04)

## 적용 내용

- `/gps_state`에 없는 `waypoint_index` 때문에 유효한 인덱스가 -1로 덮이지 않도록 수정했다. static_preview → static 전환은 근거리 트랙과 병합 점유 정보를 유지한다. M1 종료 히스테리시스는 99 idx로 설정해 M2가 idx 2400부터 활성화된다.
- 근거리 및 원거리 관측의 실제 XY 외곽을 측정 시점의 자세로 map 좌표에 보관한다. 회전할 때 과거 장애물의 외곽을 현재 자차 yaw로 회전시키지 않는다. 정지 노드와 회피 플래너는 같은 `footprint_world`를 사용한다.
- 0.5초 안 최근 5개 관측 중 서로 다른 3개 관측이 지지한 물체를 지속 보존한다. 이미 확인된 원거리 temporal 제안은 확인 상태를 인계한다. 새 관측 외곽은 즉시 충돌 검사에 사용하지만, 보존 외곽 확대는 반복 관측의 중앙값으로 결정한다. 플래너에서도 단일 프레임 확대를 별도로 영구 누적하지 않는다.
- 보존 점유는 뒤로 통과할 때까지 유지한다. 실제 움직임 확인 시 정적 보존을 해제한다. 터널 배경으로 반복 확인된 부모 점유는 해제한다. 단순 시간 만료로 확인된 물체를 없애지 않는다.
- 우측 물리 연석은 기존 차량 중심 한계 `road_width_profile`에 차량 반폭 0.95m와 기존 연석 margin을 더해 해석한다. 외곽 전체가 연석 밖일 때만 제외하며 일부가 도로에 들어온 물체는 남긴다. 저상 장애물 검출 높이와 지면제거 피팅은 유지했다.
- M8 정지는 실제 주행 경로의 유한 구간과 시간별 차체 외곽으로 검사한다. 실제 차체 겹침은 즉시 정지하며, 배경 후보의 미래 횡단 판단에는 3개 이상·0.2초 이상 일관된 세계좌표 이동을 요구한다. 배경 속도는 그 위치 이력으로 계산한다.
- 예측 시간 전체를 덮지 못하는 짧은 경로는 전체 안전으로 취급하지 않는다. 확인 가능한 남은 길이에 반응시간 0.3초·감속도 2.5m/s²의 제동 조건을 적용한 속도 상한을 `/obstacle_stop/path_speed_limit_mps`로 전달한다. 오래되거나 유효하지 않은 경로는 안전 근거로 사용하지 않는다.

## 진단과 시각화

`/obstacle_info` JSON에 `footprint_world`, `footprint_yaw`, `occupancy_state`, `occupancy_reason`, `background_exclusions`를 추가했다. 기존 ROS 메시지 타입은 유지한다.

`/obstacle_occupancy/markers`는 관측 외곽을 청록, 보존 외곽을 주황으로 표시한다. 관측이 끊긴 경우 주황 외곽과 held 상태만 남긴다. competition RViz에 표시를 추가했다.

기존 정지 진단 JSON에는 최초 정지 ID·이유, 외곽의 출처, 경로의 확인 가능 길이와 속도 상한을 추가했다. `avoidance_failed`, 정지 유지시간, 인계 보호도 구분해 확인할 수 있다.
