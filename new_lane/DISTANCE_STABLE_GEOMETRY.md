# 원거리·근거리 장애물 형상 안정화 (2026-10-04)

## 변경 내용

원거리와 근거리가 같은 `measured_geometry` 함수를 사용한다. 측정 시각의 세계좌표 점을 이용해 실제 외곽과 그 외곽의 중심·길이·폭을 함께 계산한다. 원거리 중심을 이동한 뒤 이동 전 상대좌표를 재사용하는 오류와 근거리 트랙 내부의 3m 길이 제한을 제거했다. 희소한 선형 관측의 최소 두께는 두 검출기 모두 0.35m로 통일했다. 기존 높이·점 개수·클러스터 검출 임계값은 유지했다.

현재 GroundGrid는 `velodyne_ground` 센서 원점으로 nonground 점을 발행한다. 근거리 입력도 센서 x=1.1m를 차량 원점에 반영한다. base_link 입력은 중복 이동하지 않으며 알 수 없는 프레임은 추측해 사용하지 않는다. 높이 필터는 기존 센서 z 기준을 유지한다. 이 입력 좌표 정정은 근거리 노드의 동적 구간에도 적용되지만 속도 추정 및 분류 피팅은 변경하지 않았다.

원거리 역시 최신 odom을 그대로 쓰지 않고 50Hz odom 이력에서 라이다 타임스탬프의 위치·yaw·높이를 보간한다. 0.15초 이상 오래된 자세나 0.3초를 넘는 보간 공백은 제안에 사용하지 않는다. yaw의 ±180도 경계를 처리한다.

부모 장애물은 생성 시 기준경로 접선 축을 고정한다. 확정 외곽은 현재 자차 yaw로 회전하지 않고, 접근 거리나 현재 보이는 면이 바뀌어도 유지한다. 동일 스캔의 근거리·원거리 발행은 확인 횟수를 중복 증가시키지 않는다. 크기 차이만으로 근거리 트랙 매칭을 끊지 않는다. 긴 차량의 일부 면도 기존 부모 외곽 안에서 인계하며, 별도로 검출된 인접 물체는 실제 외곽 겹침 근거 없이 합치지 않는다.

원거리 한 스캔의 이상점은 현재 충돌 외곽에는 남지만, 다른 스캔의 가까운 점으로 지지되지 않으면 보존 형상의 씨앗으로 사용하지 않는다. 반복 지원 반경은 기존 voxel 0.16m의 1.5배이다.

## 크기 갱신과 안전 조건

- 최근 0.5초의 5개 독립 관측을 보관한다. 관측 간격은 최소 0.07초이며 3개가 지지한 외곽 경계만 확정 확대에 사용한다. 0.10m 이하의 경계 흔들림은 확정 크기에 누적하지 않는다.
- 근거리에서 일부가 안 보인다는 이유로 확정 외곽을 줄이지 않는다. 기존 경계 바깥의 관측 지지점 모두를 통과해 0.20m 더 먼 반환점에 도달한 광선이 같은 3D 높이에서 3개 독립 스캔으로 확인될 때만 해당 경계를 정정한다. 광선-지지점 허용 오차는 0.08m이다.
- 무반환, 가림, 다른 높이의 광선, 0.35초 이상 오래된 스캔은 빈 공간 근거가 아니다. 보존 지지점이 2048 voxel을 넘으면 자동 축소를 중단하고 외곽을 유지한다.
- 새 실제 관측이 확정 외곽 밖에 나타나면 즉시 충돌 검사에 포함한다. 실제 위험을 평활화로 감추지 않는다.
- 보존하는 외곽은 실제 관측 다각형이다. 비스듬한 버스의 축 기준 bounding box에서 빈 모서리까지 장애물로 채우지 않는다. 기준 축의 경계 확대·정정 시 다각형을 새 경계로 잘라 갱신한다.

## 데이터 연결과 시각화

`/obstacle_info`의 기존 `footprint_world`는 확정 점유와 새로운 관측을 포함한 충돌 검사 외곽이다. `planning_footprint_world`는 안정된 회피 방향·회피량 계산용 외곽이다. `position_world`, `length`, `width`는 확정 형상을 기준으로 유지한다. `observed_footprint_world`, `geometry_state`, `geometry_reason`, `geometry_support_count`로 현재 관측과 확정 상태를 구분한다. 기존 ROS 메시지 타입은 변경하지 않았다.

회피 노드의 연결부만 수정해 회피 방향에는 확정 외곽을, 충돌 검사에는 즉시 갱신되는 안전 외곽을 사용한다. MPC 피팅·속도 제한·회피 최적화 파라미터는 변경하지 않았다.

근거리 입력의 `geometry_scan`에는 측정 시점의 센서 원점과 실제 반환점이 들어간다. 높이도 map xyz로 맞춰 다른 높이의 물체를 잘못 지우지 않는다. 한 각도 bin의 가장 가까운 반환점만 유지하고 최대 8192개 광선을 사용한다. 생략된 광선은 미확인으로 취급한다. 광선·지지점 배열은 병합 노드 내부에서 처리하고 최종 `/obstacle_info`에는 재발행하지 않는다. 같은 스캔의 광선 검색 트리는 재사용한다.

competition RViz의 `/obstacle_occupancy/markers`에서 청록은 현재 관측, 주황은 확정 회피 외곽이다. 부모 ID·확정 상태·폭·길이·held 여부를 표시한다.

## 검증과 적용

- 전체 `catkin_make -j4` 빌드와 competition.launch 파라미터 전개 확인.
- 합성 및 실제 검출 함수 회귀 테스트 163개 통과. 거리 30→20→10→5m 및 yaw 변화, 근거리·원거리 동일 점군의 동일 크기, Kalman 사용 시 연속 ID, 인계·가림·인접 물체·단일 이상점·실제 확대·3D 광선 기반 축소·비스듬한 대형 물체의 빈 모서리를 검사했다.
- 모든 MPC config YAML의 변경 전후 SHA256 일치. 고주로·회전교차로 판단, EKF, odom 50Hz 설정은 수정하지 않았다.
- 백 재생과 새 실주행 검증은 하지 않았다. 센서가 원거리에서 보지 못한 실제 면까지 완벽하게 추정했다는 의미는 아니다. 추가로 확인되는 실제 점유는 확정 크기를 정정할 수 있다.
- 토탈 런치를 재시작해야 새 검출·병합·회피 연결부가 함께 적용된다. 실행 중인 런치는 자동 재시작하지 않았다.
